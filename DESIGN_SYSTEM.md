# Staffio Industrial-Luxury Design System

## Core Aesthetic: "Dark Industrial-Luxury"

A high-performance, brutalist structural layout merged with premium, high-contrast visual refinement. 

### Visual Directives

- **Geometry**: Sharp edges (4-8px radius maximum). Precision grid alignments (8px base unit).
- **Contrast**: Juxtaposition of deep obsidian/navy bases with vibrant, glowing primary accents and metallic luxury highlights.
- **Feel**: Premium, heavy, responsive, and hardware-accelerated.

## Component Architecture

### Buttons

- **Shape**: Sharp corners (4px radius).
- **Interaction**: Fast, high-contrast hover states. Hardware-accelerated scale-on-click (0.98x).

### Industrial Cards

- **Signature**: Corner marks on all four corners.
- **Border**: Thin 1px stroke (`#1F1F1F`).
- **Background**: Glassmorphism/Dark gradient.

### Grid System

- **Base Unit**: 8px
- **Layout**: Columnar grid with strict alignment to the industrial "unit" blocks.
